# Jungle Gaming — Frontend Challenge (workspace de execução)

Este repositório contém **documentação, arquitetura, regras e plano de trabalho para o Cursor Cloud Agent**. Ele **não contém ainda a aplicação executável**: o agente deverá implementar o código sob a supervisão do Cauã.

## Fontes oficiais
- Desafio e critérios completos: https://github.com/junglegaming/frontend-challenge/blob/main/README.md
- Figma (referência visual principal): https://www.figma.com/design/Ff0SksUi7UFtPWUO8kyNtw/Frontend-Challenge?node-id=0-1
- Link de entrega comunicado por e-mail: https://entrevistas.45-55-130-35.sslip.io/testes/front-remoto

## Início
1. Leia `START_HERE.md`.
2. Configure conexão Figma MCP (ou forneça capturas/exportações legais do layout).
3. Inicie um Cursor Cloud Agent neste repositório e cole o conteúdo de `PROMPT_CURSOR_CLOUD.md`.
4. Acompanhe o `TASKS.md` que o agente criar e as evidências reais de execução.

**Fonte da verdade:** README oficial. Este pacote é um plano opinativo, não uma implementação já testada e nem substitui o enunciado. Não invente que a fidelidade ao Figma foi verificada: o acesso ao arquivo falhou na análise preparatória.
